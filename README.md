# Laboratorio IV - Programación II

Laboratorio de preparación para el Primer Parcial de Programación II.

## Contenido

El laboratorio incluye ejercicios relacionados con:

- Programación Orientada a Objetos.
- Herencia.
- Encapsulamiento.
- Polimorfismo.
- Abstracción.
- Manejo de excepciones.
- Arreglos.
- Estructuras de control.
- Diagramas UML.
- Git y GitHub.

## Herramientas

- Java
- Visual Studio Code
- Extension Pack for Java
- Git
- GitHub

## Organización

El proyecto contiene 16 ejercicios independientes.

Cada ejercicio se encuentra organizado dentro de su propia carpeta.
