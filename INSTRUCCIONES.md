# LABORATORIO IV - PREPARACIÓN PARA PRIMER PARCIAL

## Objetivo

Reforzar los conocimientos adquiridos en el Módulo I mediante la resolución de ejercicios prácticos similares a los que se evaluarán en el primer parcial.

Adicionalmente, continuar fortaleciendo el uso de herramientas de control de versiones, asegurando una correcta gestión y seguimiento del código desarrollado.

## Metodología

- Desarrollo individual.
- Resolver los ejercicios en el orden sugerido.
- Utilizar nombres claros en variables, métodos y clases.
- Mantener código ordenado y legible.
- Mantener una organización adecuada del proyecto.
- Ejecutar y verificar cada ejercicio antes de versionarlo.
- Utilizar Git para el control de versiones.
- Utilizar mensajes de commit claros y descriptivos.
- Subir el repositorio a GitHub.

# EJERCICIOS

- Método abstracto hacerSonido().

- Clase Gato.

En main:
- Crear objetos.
